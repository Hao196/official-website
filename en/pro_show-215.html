Shaft-Type Stranding Machine

This machine is a complete multi-strand twisting unit specially designed for manufacturing high-quality control cables and fiber optic cables. Redesigned with reference to advanced cabling equipment at home and abroad and combined with the actual requirements of wire and cable production, the machine consists of a pay-off stand, wire guide die holder, central wrapping unit, serving unit, rotating length counter, cantilever-arm tub twister and safety guards.

The machine is controlled by a PLC program. Frequency-converter motor controllers keep the output shaft speed essentially constant, with stepless adjustment via the computer. All parameters can be set freely from the operator panel, and the operating interface does not interfere with the main machine. Acceleration and deceleration are highly linear, with a lay error within 2%. Automatic meter counting is provided; when the preset length is reached, the main machine and the wrapping unit automatically decelerate smoothly to a stop.
